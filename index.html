Nordljus Design AB
Cloud Transformation

Welcome to my cloud portfolio! I designed and built a complete Microsoft Azure environment for Nordljus Design AB, a 12-person interior design agency in Sweden. My main focus was making sure their data stays strictly inside the EU for GDPR rules, keeping access secure with least-privilege policies, and making sure monthly costs stay low.

Consultant: Taimur Hassan
Primary Region: Sweden Central
Date: October 2026

Project Brief & Business Scenario

I helped Nordljus Design AB move away from their old setup and build a modern, secure cloud footprint in Azure's Sweden Central region. I set up secure file sharing for their team, hosted their public company website, built an admin server for IT work, and made sure everyone only has access to what they actually need.

1. Management (Ledning)

2 Employees

Business Need: Wants to see overall progress and costs without changing or deleting anything.

  • Azure Solution: I assigned them the Reader role on resource group rg-nordljus-001 so they can view everything safely.

2. Design Dept

6 Employees

Business Need: Needs a place for design blueprints and a way to share files safely with clients.

  • Azure Solution: I created a design container in Blob Storage (stnordljusdesign001) and gave them temporary SAS links over HTTPS.

3. Finance (Ekonomi)

3 Employees

Business Need: Needs private storage for invoices and private company contracts.

  • Azure Solution: I set up a private ekonomi container that only finance team members can open.

4. IT Administration

1 Employee

Business Need: Needs full control to manage servers, tools, and the company web app.

  • Azure Solution: I assigned the Contributor role, set up a Linux VM (vm-nordljus-it-001) with auto-shutdown, and deployed the web app (app-nordljus-web-001).

Phase 5

Root Cause Analysis & Troubleshooting Journey

How I Fixed Errors: Whenever I hit an error during this deployment, I used logs and diagnostics to figure out what was wrong and fix it. Here is my personal troubleshooting workflow for the 4 key issues.

Issue 1: NSG Firewall Rule Priority Issue 2: SSH Connection Timeout Issue 3: App Service 404 Error Issue 4: Web App Container Startup

My Troubleshooting Notes & Solutions

1. NSG Firewall Rule Priorities

Scope: nsg-nordljus-001 | Port 22

What Happened: I checked my NSG rules to see why traffic was behaving unexpectedly. Azure reads rules from top to bottom based on the priority number (lowest numbers get checked first).

How I Fixed It: I adjusted my Port 22 SSH rule priority so my admin rules run before the default deny rules kick in.

2. SSH Connection Timeout

Scope: vm-nordljus-it-001 | Terminal

What Happened: My terminal gave me a Connection timed out error when trying to connect to the VM. This told me the firewall was silently dropping my traffic at the edge instead of the VM rejecting it.

How I Fixed It: I updated the NSG rule to explicitly allow SSH connections from my own public IP address.

3. App Service 404 Deployment Error

Scope: app-nordljus-web-001 | Web Hosting

What Happened: The website showed a 404 error page after deployment. I checked the App Service Log Stream and saw that files were put in the wrong folder path.

How I Fixed It: I made sure the web assets were placed properly in /home/site/wwwroot so Azure could find the index file.

4. Web App Startup Settings

Scope: app-nordljus-web-001 | Configuration

What Happened: The web container failed to start because it didn't know which command to run to start serving pages.

How I Fixed It: I went to App Service Configuration and added a clear startup command: npx serve -s /home/site/wwwroot -l 8080.

Engineering Analysis

What I Learned & Future Plans

Security & Protection

I learned how important zero-trust security is. Restricting SSH access with NSG rules and using SAS tokens for storage makes sure data stays completely safe.

Cost Management

Setting up auto-shutdown rules on virtual machines saves significant money over time by making sure we never pay for idle servers overnight.

Future Growth

Building everything in Sweden Central gives us a clean base. If the company expands across Europe later, we can easily add Azure Front Door to handle global traffic.
